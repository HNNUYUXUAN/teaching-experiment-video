# 交付结构与字段

在用户指定的项目目录建立新版本制作目录。推荐按实际需要保存：

- 原片核对表：source、in_us、out_us、观察、解释、限制。
- 分镜表：shot_id、目的、素材、原片取段、start_us、end_us、旁白段号。
- 音频清单：id、text、audio、lead_ms、tail_ms；有硬约束才设 slot_ms。
- 时间线：视觉素材、旁白、伴奏和字幕的独立轨道与对应关系。
- 交接文档：导入顺序、字幕样式、播放检查与导出要求。
- 验收报告：编码/尺寸/帧率/时长/字节数/哈希、检查方式和状态。

图片和视频在导入目录按出现顺序共用数字编号，音频另行编号。时间线以整数微秒为准，字幕以毫秒为准；舍入差在允许的静态画面中吸收，不拉伸实验动作来掩盖误差。

可复用示例使用相对路径；本机实际导入映射可在运行时解析绝对路径。共享资料前移除用户名、账号、工作空间标识、签名下载链接、密钥、令牌和私有目录，只留下任务所需的相对路径与可配置字段。

媒体核验示例（先安装并确保 ffmpeg、ffprobe 在 PATH）：

```powershell
python scripts/media_audit.py final.mp4 --max-bytes 100000000 --expected-duration 120 --report media-audit.json
```

将示例的时长和文件名替换为当前目标。脚本只读取视频并创建新报告，不覆盖已有报告，不调用云服务。报告不包含输入文件的绝对路径。缺少依赖时停止，使用者按其环境维护规则提供工具。
