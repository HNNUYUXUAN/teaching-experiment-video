# 三条图片生成路径

## 共同输入与验收

每张图先准备独立 UTF-8 提示词：教学目的、画面比例、精确中文、需要表达的物理关系、布局、字幕留白、参考素材和验收点。编号与分镜一致。不要一次批量生成整部视频后才检查。

验收：能打开原图；尺寸和格式符合目标；逐字检查文字；公式、光路、颜色和箭头正确；没有被当成实拍证据；字幕区不遮挡内容。保存来源类型、模型或会话位置、提示词哈希、文件哈希与验收状态。不得把“工具成功返回”当作内容正确。

## A. 当前 Agent 原生生图

用户指定或选择 auto 且 Agent 有可用工具时，可调用原生图片生成能力。
1. 读取宿主图像工具说明和参数，不能假定有某个固定函数。
2. 将本张提示词及获准的参考图传入，等待实际生成结果。
3. 通过工具提供的下载/保存方式取得原图，放入项目 images 目录。
4. 逐张视觉核验；失败时写清具体改动再做有限次修订，不重复无限尝试。
5. 记录 image_provider=agent。如果工具只返回远程地址，按宿主允许的方式保存；无法获取可用文件就标记待下载。

## B. Chrome / Edge 中使用 ChatGPT

先按 agent-adapter.md 完成连接与登录。
1. 在实际可见的 ChatGPT 页面开始适合本张图的对话，必要时进入用户指定项目；保留其组织方式。
2. 在可见输入框提交完整生图请求，必要时选择页面提供的图像创建功能。不要猜 DOM 选择器或固定坐标；每次动作后重读页面。
3. 等待可见图片生成完成；若限额、订阅、验证码或登录阻塞，暂停交给用户，不自动升级套餐。
4. 使用界面提供的原图下载功能保存，核对下载文件名、实际像素尺寸和图片内容。网页截图不替代原始图片文件。
5. 如页面提供图片编辑，携带具体修改要求修订；每轮保留可回退原件。
6. 没有浏览器控制工具时输出提示词供用户手动执行。用户提供原图后从验收步骤继续。

只有当前页面明确提供的交互功能可以使用；不调用私有 ChatGPT API，不复制 cookie 或凭据。

## C. 阿里云百炼 Qwen-Image

先完成 .env 配置与用户对本次云生图的授权。脚本使用官方 DashScope 同步接口，支持 Qwen-Image 这一接口形状；不假设其他万相/异步模型能直接替换模型名。

将 assets/image-request.example.json 复制到项目 prompts，按教学内容修改 prompt、size、seed。先做不联网检查：

```powershell
& ./scripts/run.ps1 -Script images --request $requestFile --output $newPng --dry-run
```

有明确任务授权后调用：

```powershell
& ./scripts/run.ps1 -Script images --request $requestFile --output $newPng --allow-paid
```

Linux/macOS 对应 `bash scripts/run.sh images --request ... --output ... --allow-paid`。

参数使用真实路径。输出为新 PNG、同名 .image.json。请求开始会创建 .pending.json；超时或下载失败保留该标记，防止重复收费。确认请求结果之前不要删除标记或换文件名重试。服务可能已生成且计费，此时应先在控制台查询或人工恢复下载。

API Key 只用于指定官方接口的 Authorization 请求头；下载图像不带 Key。脚本不跟随鉴权请求重定向，不把签名 URL 写入输出。生成成功后仍需人工/视觉工具逐图验收。

2026-10-25 已查阅的官方说明支持 qwen-image-2.0-pro 同步调用；Key 和 endpoint 的地域应一致，结果 URL 应及时下载。若用户选择另一模型，先读取其当前官方接口文档并适配请求、轮询及结果字段，新增离线测试后再调用，不盲目复用此脚本。

## 路由决策

优先满足用户明确选择。auto：当前 Agent 原生生图可用则用它；否则用已连接且已登录的 ChatGPT；否则在用户允许百炼且配置齐全时使用百炼；最后提供手动生成包。切换费用来源、账号或服务时告知用户并取得必要授权。

三条路线都不可用时，继续完成原片证据、分镜、旁白和图片提示词；图片阶段标为 blocked，并说明用户需提供的连接、授权或成品图。

官方依据：[千问文生图 API](https://help.aliyun.com/zh/model-studio/qwen-image-api)。
